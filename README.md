# Polar Go

Open-source privacy-first mobile web browser combining the best of **Chrome, Opera, and DuckDuckGo**, styled in **Royal Blue, Powder Blue, Silver, and White** with a custom **Polar Bear Globe** logo.

## Features
- **Auto-Clear History on Close:** Automatically wipes browsing history, cookies, cache, and local storage whenever the app is closed or backgrounded (toggleable in Privacy Settings).
- **One-Tap Burn Button:** DuckDuckGo-style fire icon in the top bar instantly clears all open tabs, history, cookies, and cache.
- **Opera-Style Speed Dial:** Quick-launch start page with pinned shortcuts.
- **Multi-Tab Support:** Open, switch, and close multiple tabs with a live tab counter badge.
- **Search Engine Switcher:** Choose between **DuckDuckGo**, **Google**, **Brave Search**, and **Ecosia**.
- **Built-in Tracker & Ad Shield:** Blocks common ad and analytics tracker domains automatically and counts blocked requests.

## Build Your APK in the Cloud (No Local Setup Required)
1. Create a free repository on GitHub (e.g., `polar-go`).
2. Extract this ZIP and upload all files (including `.github/workflows/build_apk.yml`) to the `main` branch.
3. Open the **Actions** tab -> **Build Polar Go APK**.
4. Download **`PolarGo-APK`** from the **Artifacts** section, unzip it, and install `PolarGo-release.apk` on your Android phone.
